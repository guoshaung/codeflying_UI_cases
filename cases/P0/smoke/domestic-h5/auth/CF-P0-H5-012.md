# CF-P0-H5-012 分享给好友

- 优先级：P0
- 模块：国内H5 / 登录后首页 / 应用名称后操作按钮
- 平台：国内H5
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：加载对应端的 Playwright session；需要应用时使用稳定、非转圈的测试应用。
- Agent 分组：h5_workspace_runner
- 账号类型：default-playwright-session
- 是否修改数据：no
- 数据锁：`account:{phone}`
- 清理动作：无；若产生临时数据则按 test_run_id 清理
- 人工测试原因：真实好友接收结果需人工/外部 App 验证，自动化只验证入口和复制/分享触发链路。
- XMind 原始标记：`priority-1`

## 测试步骤

1. 创建独立的 国内H5 Browser Context，使用移动端 viewport，并加载 `default-playwright-session`。
2. 打开真实 H5 入口：`https://www.codeflying.net/codeflying_h5/`，进入登录后首页/应用列表区域。
3. 停留在应用列表外层，选择一个稳定、非转圈、非生成中的应用卡片。
4. 点击应用名称旁边的三点/更多操作按钮，打开底部半屏菜单；**不要点击应用卡片主体进入预览页**。
   - 操作按钮通常是卡片底部/名称旁的 `uni-image` 三点图标，可能无文字、内层 img 透明但可点击。
   - 禁止只用 `text=` 查找；应在目标卡片 `.appBodyText` 区域内定位应用名称右侧的 `uni-image`。
5. 点击菜单中的分享入口（如“分享给好友”或“分享应用”）。
6. 若出现分享弹窗或复制链接弹窗，读取弹窗展示的分享 URL。
7. 点击“复制链接”按钮，并通过 Playwright 浏览器上下文读取剪贴板。
8. 记录页面状态、URL、关键 DOM、接口结果、剪贴板文本和截图。

## 预期结果

1. 分享入口可用，且触发分享弹窗、复制链接、二维码、系统分享面板或相关业务接口之一。
2. 若存在复制链接按钮，点击后剪贴板内容为非空 `http(s)` URL，并与弹窗展示链接一致或包含同一分享地址。
3. 页面无白屏、无未处理报错，相关功能可继续操作。

## 通过标准

- 分享入口存在且可点击，并触发分享相关 UI 或接口。
- “复制链接”场景必须验证实际复制副作用：剪贴板为非空 `http(s)` URL。只看到按钮或 toast 不足以判定 PASS。
- 不要求自动化完成真实好友接收动作；该部分属于人工验收或外部系统能力，可记录 `MANUAL_REQUIRED`。

## 失败条件

- 分享入口不存在、点击无响应、分享弹窗/接口未触发。
- 复制链接后剪贴板为空、不是 URL、或明显不是当前分享地址。
- 页面出现错误状态或不可继续操作。

## 阻塞条件

- 测试环境、账号、外部分享面板权限、剪贴板权限或必要测试数据不可用。

## 证据要求

- 操作前后截图。
- 分享弹窗/菜单截图。
- 剪贴板文本或读取失败的权限错误。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。

## 备注

- 该用例必须在 H5 应用列表外层通过三点菜单测试，不要误点应用主体导致进入预览后找不到分享入口。
