# CF-P0-H5-004 点击应用进入应用页面

- 优先级：P0
- 模块：国内H5 / 未登录首页 / 应用卡片
- 平台：国内H5
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：新建无登录态 Browser Context，不加载 storageState；必须使用真实 H5 入口。
- Agent 分组：h5_workspace_runner
- 账号类型：anonymous（不加载 Playwright session）
- 是否修改数据：no
- 数据锁：`none`
- 清理动作：无
- 人工测试原因：无
- XMind 原始标记：`priority-1`

## 测试步骤

1. 创建独立的 国内H5 Browser Context，使用移动端 viewport，**不加载 Playwright session**。
2. 打开真实 H5 入口：`https://www.codeflying.net/codeflying_h5/`。
   - 禁止只打开 PC 站后切换 viewport 充当 H5。
   - 若直接重定向到登录页、PC 页、国际站或白屏，应记录 URL/DOM/截图，并按入口不可用或登录前置限制处理。
3. 在未登录首页/首页应用列表区域选择一个可见应用卡片。
4. 点击应用卡片主体或明确的“查看/体验/进入”入口。
5. 等待页面跳转、详情弹窗、预览弹窗或应用体验页出现。
6. 记录页面状态、URL、关键 DOM、接口结果和截图。

## 预期结果

1. 点击应用后应进入应用页面、应用详情、应用体验弹窗或等价的可继续体验状态。
2. 页面无白屏、无未处理报错，相关功能可继续操作。

## 通过标准

- 出现应用详情/体验弹窗、URL 进入应用相关路由、或页面展示当前应用的详情/体验内容之一即可 PASS。
- 如果当前产品设计为匿名态应用卡片仅展示不可点击，必须有明确禁用态/提示；否则点击无响应应记录为 FAIL。
- 自动化证据完整；若有重试，必须记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 应用卡片可见但点击无响应、无任何提示、URL/弹窗/DOM 均无变化。
- 点击后白屏、JS 报错导致页面不可继续操作。

## 阻塞条件

- 真实 H5 入口不可用、被强制重定向、应用列表无数据、测试环境或必要数据不可用。

## 证据要求

- 操作前后截图。
- 页面 URL 与关键 DOM 状态。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。

## 备注

- 本用例来自 XMind 冒烟测试。执行时以真实 H5 路由为准，不用 PC 站 viewport 替代。
