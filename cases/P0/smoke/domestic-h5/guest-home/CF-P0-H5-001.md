## 自动化定位补充

- H5 入口固定为 `https://www.codeflying.net/codeflying_h5/`，必须按 SKILL 的「H5 移动设备上下文」用 CDP 在当前 page 上做 iPhone 模拟（UA + 触摸 + 390x844）后再导航。**只 resize 不换 UA 会被服务端 302 到 PC 首页 `/`**，那是 Element UI 桌面站，本用例元素全部不存在。导航后先断言 `location.href` 仍含 `/codeflying_h5/`。
- 输入框是 uni-app 的 `textarea`（页面只有一个），**不要用 `.el-textarea__inner`**；「立即开发」按钮是 `.send-button`。
- 断言：点击后 URL 变为 `https://www.codeflying.net/codeflying_h5/pages/login/login`，页面出现「请输入手机号 / 请输入验证码 / 获取验证码」。不要在登录页真正提交手机号。
- 已知非阻塞现象：首页 bundle `pages-index-index.*.js` 会打出两条 `TypeError: Cannot read properties of undefined (reading 'apps')`。这是真实产品缺陷，需单独报缺陷单，但**不影响本用例跳转**，不得据此判 FAIL。
