# CF-P0-H5-037 点击跳转至在线客服对话页

- 优先级：P0
- 模块：国内H5 / 个人中心 / 在线客服
- 平台：国内H5
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：加载对应端的 Playwright session；需要应用时使用稳定、非转圈的测试应用。
- Agent 分组：profile_support_agent
- 账号类型：default-playwright-session
- 是否修改数据：no
- 数据锁：`none`
- 清理动作：无；若产生临时数据则按 test_run_id 清理
- 人工测试原因：无

## 测试步骤

1. 创建独立的 国内H5 Browser Context，使用移动端 viewport，并加载 `default-playwright-session`。
2. 打开真实 H5 入口：`https://www.codeflying.net/codeflying_h5/`。
3. 进入“个人中心”页面，确认用户信息区域已渲染。
4. 点击“在线客服”入口。
   - 该入口可能使用 `javascript:void(0)`、Vue `@click` 或新窗口/内嵌客服 SDK 事件，普通 Playwright `.click()` 可能不触发。
   - 点击优先级：`page.evaluate(() => targetElement.click())` → `locator.dispatchEvent('click')` → `click({ force: true })`。
   - 同时监听 URL 变化、popup/new page、客服 iframe、客服浮层、聊天窗口 DOM 和客服相关接口。
5. 等待跳转至在线客服对话页、打开客服浮层/iframe、新窗口，或出现可输入客服消息的对话区域。
6. 记录页面状态、URL、关键 DOM、接口结果和截图。

## 自动化定位补充

- 固定入口：`https://www.codeflying.net/codeflying_h5/`；加载 member/www session 后落在 `/my-home` 是正常行为。
- 在线客服主选择器：`.help.cs-trigger`；备选：可见文本 `Support` 或 `在线客服`。
- 点击后主断言：`.customer-service-dialog` 可见，且容器内出现 `.chat-message-list`、`textarea` 或消息输入框之一。
- 点击顺序：DOM 原生 click → dispatchEvent click → force click；每步等待 1 秒并检查 popup、iframe、dialog。
- 不发送聊天内容；本 case 只验证客服会话 UI 可用。

## 预期结果

1. 点击在线客服后，应跳转至在线客服对话页，或展示客服聊天浮层/iframe/新窗口。
2. 页面无白屏、无未处理报错，相关功能可继续操作。

## 通过标准

- 出现客服对话页、客服聊天窗口、客服 iframe、新窗口或可输入消息的客服 UI 之一即可 PASS。
- 如外部客服 SDK 加载较慢，可等待合理时间并记录接口/DOM 证据；不得只因普通 click 无响应直接判定 FAIL。

## 失败条件

- 在线客服入口存在，但按上述 JS 触发策略后仍无任何 URL、popup、DOM 或接口变化。
- 客服页面/弹窗白屏、报错或不可继续操作。

## 阻塞条件

- 登录态失效、H5 入口不可用、客服第三方服务不可用、测试环境或必要数据不可用。

## 证据要求

- 操作前后截图。
- 页面 URL、popup/new page URL、客服 iframe/聊天 DOM 状态。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。

## 备注

- 本用例应优先验证在线客服入口和客服 UI 是否可达，不要求真人客服回复。
