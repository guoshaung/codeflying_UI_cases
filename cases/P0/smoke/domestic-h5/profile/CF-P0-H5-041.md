# CF-P0-H5-041 点击立即购买按钮浏览器环境拉起支付宝

- 优先级：P0
- 模块：国内H5 / 个人中心 / 会员类型 / 充值会员
- 平台：国内H5
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：付费用户
- 前置条件：加载对应端的 Playwright session；需要应用时使用稳定、非转圈的测试应用。
- Agent 分组：membership_credit_agent
- 账号类型：default-playwright-session
- 是否修改数据：yes
- 数据锁：`payment:{account_id}`
- 清理动作：使用 mock/沙箱；不得产生真实扣款
- 人工测试原因：真实支付拉起/完成需人工/沙箱专项；本用例只验证点击立即购买后支付宝拉起入口。

## 测试步骤

1. 创建独立的 国内H5 Browser Context，使用移动端 viewport，并加载 `default-playwright-session`。
2. 打开真实 H5 入口：`https://dev.codeflying.net/codeflying_h5/`。
3. 必须先点击底部导航“个人中心”，进入真实个人中心页面；不能停留在首页/发现页直接查找“充值会员”。
4. 确认用户信息和会员卡片区域已渲染，页面应出现“尊享版/免费版/会员类型/在线客服/退出登录”等个人中心特征之一。
5. 点击“充值会员 / 立即购买 / 购买会员”等会员购买入口，进入购买会员页面。
   - H5 个人中心按钮常绑定 Vue Router JS 事件（`javascript:void(0)` 或 `@click`），普通 Playwright `.click()` 可能不触发。
   - 点击优先级：`page.evaluate(() => targetElement.click())` -> `locator.dispatchEvent('click')` -> `click({ force: true })`。
   - 禁止只执行普通 `.click()` 后无跳转就直接判定 FAIL。
6. 在购买会员页面选择任一会员套餐，点击“立即购买”按钮，支付方式选择“支付宝”。
7. 观察浏览器环境是否拉起支付宝：跳转至支付宝 H5 收银台（如 `mclient.alipay.com` / `render.alipay.com`）或触发支付宝 schema/拉起交互。
8. 记录页面状态、URL、关键 DOM、接口结果和截图。

## 预期结果

1. 点击立即购买（支付宝）后，浏览器环境拉起支付宝，进入支付宝 H5 收银台或出现支付宝拉起交互。
2. 页面无白屏、无未处理报错。
3. 不要求真实付款成功，只需验证支付宝拉起入口/跳转正确。

## 通过标准

- 出现支付宝 H5 收银台页面、支付宝拉起 schema、或等价支付宝支付前置 UI 之一即可 PASS。
- 如因支付需要真人/沙箱操作，只要拉起入口和支付宝前置 UI 正常出现，可判自动化 PASS 或记录后续 `MANUAL_REQUIRED`。

## 失败条件

- 点击立即购买后无任何支付宝拉起/跳转，或跳转后页面白屏、报错、无法继续操作。
- 按上述 JS 触发策略后仍无响应。

## 阻塞条件

- 登录态失效、H5 入口不可用、会员/支付服务不可用、支付宝沙箱/支付通道不可用、测试环境或必要数据不可用。

## 证据要求

- 操作前后截图。
- 页面 URL 与关键 DOM 状态。
- 支付宝拉起/收银台页面截图及 URL。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。

## 备注

- 本用例自动化边界是“点击立即购买后拉起支付宝入口/跳转”，不是完成真实支付。
- 必须使用 mock/沙箱，不得产生真实扣款。
