# CF-P0-H5-033 点击弹出二次确认弹窗

- 优先级：P0
- 模块：国内H5 / 工作台 / 已发布 / 应用操作 / 删除应用
- 平台：国内H5
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：加载会员 Playwright session；准备本轮专用的一次性应用，名称使用 `E2E_DELETE_<run_id>`，禁止复用或删除已有稳定应用。
- Agent 分组：app_lifecycle_agent
- 账号类型：default-playwright-session
- 是否修改数据：yes
- 数据锁：`app:{app_id}`
- 清理动作：本用例真实删除 `E2E_DELETE_<run_id>` 一次性应用，并确认不存在残留
- 人工测试原因：无

## 测试步骤

1. 使用会员账号准备本轮专用的一次性应用 `E2E_DELETE_<run_id>`：优先复制/做同款得到当前账号拥有的副本，并确认应用已停止转圈且可正常预览；不得使用已有稳定应用。
2. 在该一次性应用预览页点击 `button.upgrade-button` 内文字为“好呀”的按钮；若页面已处于在线模式，可直接进入下一步。
3. 点击“进入在线模式”，等待在线状态成功，记录应用 `app_id`、名称、状态和截图。这里的在线操作仅用于制造“已发布可删除”测试数据，不计作发布功能 PASS。
4. 创建独立的国内 H5 Browser Context，加载同一会员账号登录态；打开 `https://www.codeflying.net/codeflying_h5/` 并进入“工作台/我的应用”。
5. 停留在应用列表外层，切换到“已发布” tab，按名称精确找到 `E2E_DELETE_<run_id>` 卡片。
6. 点击该卡片应用名称旁的三点/更多操作按钮，打开底部半屏菜单；不要点击卡片主体。
7. 点击“删除应用”，确认二次确认弹窗出现；再次核对弹窗中的应用名称/app_id 后，点击确认删除。
8. 等待删除接口业务成功并刷新列表，验证 `E2E_DELETE_<run_id>` 不再出现在“已发布”和“未发布”列表，且应用详情不可继续访问。
9. 保存删除前、确认弹窗、删除后列表截图以及接口业务响应；报告不得把步骤 2-3 写成“发布功能已通过”。

## 预期结果

1. 一次性应用能通过“好呀”→“进入在线模式”进入已发布/在线状态。
2. 已发布列表中能找到该一次性应用，删除二次确认弹窗正常出现。
3. 确认删除后接口业务成功，该应用从列表和详情中消失。

## 通过标准

- 必须同时具备删除确认弹窗、删除接口业务成功、删除后列表/详情不存在三类证据才可 PASS；只看到弹窗不足以通过。
- 自动化证据完整；若有重试，必须记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 一次性应用无法进入在线模式、已发布列表找不到该应用、删除确认弹窗未出现、删除接口失败，或确认删除后应用仍存在。

## 阻塞条件

- 无法创建/复制一次性测试应用，或账号已达到在线应用额度且无法准备安全删除的数据。

## 证据要求

- 操作前后截图。
- 页面 URL 与关键 DOM 状态。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。
- 涉及数据变化时，保存变化前后数据及清理结果。

## 备注

- 本用例允许真实删除，但只能删除名称和 app_id 均与本轮记录一致的 `E2E_DELETE_<run_id>` 一次性应用。任何不匹配都必须停止，不得误删。
