# CF-P0-H5-028 点击发布应用弹出toast提示

- 优先级：P0
- 模块：国内H5 / 工作台 / 已发布 / 应用操作 / 查看对话过程 / 卡片信息
- 平台：国内H5
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：加载对应端的 Playwright session；需要应用时使用稳定、非转圈的测试应用。
- Agent 分组：app_lifecycle_agent
- 账号类型：default-playwright-session
- 是否修改数据：yes
- 数据锁：`app:{app_id}`
- 清理动作：清理本轮创建的应用或恢复名称、发布状态
- 人工测试原因：无

## 测试步骤

1. 创建独立的 国内H5 Browser Context，使用移动端 viewport，并加载 `default-playwright-session`。
2. 打开真实 H5 入口：`https://dev.codeflying.net/codeflying_h5/`，进入“工作台”。
3. 切换到“已发布” tab，选择一个稳定、非转圈、非生成中的应用卡片。
4. 点击该应用名称旁边的三点/更多操作按钮，选择“查看对话过程”。
5. 在对话过程页找到应用卡片信息中的“发布应用”入口并点击。
6. 验证发布类型弹窗出现，且弹窗内同时展示“微信小程序发布”和“鸿蒙小程序发布”。
7. 截图后关闭弹窗；不要点击具体发布类型，不要生成/识别二维码，也不要真实发布。

## 预期结果

1. 点击“发布应用”后发布类型弹窗正常出现，并展示“微信小程序发布”和“鸿蒙小程序发布”。
2. 页面无白屏、无未处理报错，相关功能可继续操作。

## 通过标准

- 发布类型弹窗可见且两个发布类型均可识别即 PASS；不要求二维码出现或可识别。
- 自动化证据完整；若有重试，必须记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 发布类型弹窗未出现，或缺少“微信小程序发布”/“鸿蒙小程序发布”任一项。

## 阻塞条件

- 测试环境、账号、第三方服务或必要测试数据不可用。

## 证据要求

- 操作前后截图。
- 页面 URL 与关键 DOM 状态。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。
- 涉及数据变化时，保存变化前后数据及清理结果。

## 备注

- 本用例只验证发布弹窗，不执行真实发布。
