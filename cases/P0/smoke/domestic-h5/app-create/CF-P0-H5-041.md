# CF-P0-H5-041 点击立即开发按钮进入需求澄清页面

- 优先级：P0
- 模块：国内H5 / 应用创建 / 文本框内输入需求文案
- 平台：国内H5
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：加载对应端的 Playwright session；默认使用 `default-playwright-session`。
- Agent 分组：h5_workspace_runner
- 账号类型：default-playwright-session
- 是否修改数据：yes
- 数据锁：`app:{app_id}`
- 清理动作：本用例只验证进入需求澄清页，不提交生成；通常无新应用需要清理。
- 人工测试原因：无
- XMind 原始标记：`priority-1`

## 测试步骤

1. 创建独立的 国内H5 Browser Context，使用移动端 viewport，并加载 `default-playwright-session`。
2. 打开真实 H5 入口：`https://www.codeflying.net/codeflying_h5/`。
   - 禁止只打开 PC 站后切换 viewport 充当 H5。
3. 进入 H5 首页或登录后首页，寻找“立即开发 / 创建新应用 / 开始创建 / 说中文做应用”等应用创建入口。
4. 点击创建入口进入需求澄清页面。
   - H5 页面按钮可能绑定 Vue Router JS 事件（`javascript:void(0)` 或 `@click`），普通 Playwright `.click()` 可能不触发。
   - 触发优先级：普通 `.click()` → `page.evaluate(() => targetElement.click())` → `locator.dispatchEvent('click')` → `click({ force: true })` → 直接访问 H5/PC 等价创建路由（如 `/develop` 或 H5 创建页）验证页面可达。
   - 直接访问等价创建路由只作为 fallback，必须记录前面点击入口失败的证据。
5. 等待出现需求输入框、提示词气泡、需求澄清标题、创建应用按钮或“描述你想要做的应用”等关键文案。
6. 记录页面状态、URL、关键 DOM、接口结果和截图。

## 预期结果

1. 点击立即开发/创建入口后进入需求澄清或创建应用页面。
2. 页面存在需求输入框或可继续输入需求的 UI。
3. 页面无白屏、无未处理报错，相关功能可继续操作。

## 通过标准

- URL 进入创建/需求澄清相关路由，或页面出现需求输入框、提示词气泡、创建应用按钮、需求澄清相关文案之一即可 PASS。
- 如果普通点击失败，但 fallback 通过 JS 事件触发或等价路由进入页面，应标记 `RETRY_PASS`，不得判 FAIL。
- 本用例只验证“进入需求澄清页面”，不要求提交需求或等待应用生成完成。

## 失败条件

- 创建入口存在，但所有触发策略均无效，且无法进入任何需求澄清/创建应用页面。
- 进入后页面白屏、报错或无可输入需求的 UI。

## 阻塞条件

- 登录态失效、真实 H5 入口不可用、H5 首页无法渲染、测试环境或必要数据不可用。

## 证据要求

- 操作前后截图。
- 页面 URL 与关键 DOM 状态。
- 如使用 fallback，记录普通点击失败现象与 fallback 成功证据。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。

## 备注

- 该用例应与 CF-P0-H5-042 连续执行：041 进入需求澄清页后，042 直接复用当前页面输入提示词。
