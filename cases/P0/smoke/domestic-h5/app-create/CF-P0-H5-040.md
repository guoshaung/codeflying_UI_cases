# CF-P0-H5-040 提示词文案进入文本输入框

- 优先级：P0
- 模块：国内H5 / 应用创建 / 点击提示词气泡
- 平台：国内H5
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：CF-P0-H5-039 已进入需求澄清/创建应用页面；或本用例自行按 041 的步骤进入该页面。
- Agent 分组：app_lifecycle_agent
- 账号类型：default-playwright-session
- 是否修改数据：yes
- 数据锁：`app:{app_id}`
- 清理动作：本用例只验证提示词进入输入框，不提交生成；通常无新应用需要清理。
- 人工测试原因：无

## 测试步骤

1. 优先复用 CF-P0-H5-039 成功后的当前页面；若单独执行，则先按 CF-P0-H5-039 进入需求澄清/创建应用页面。
2. 定位页面下方的提示词气泡按钮，优先选择 `button.quick-card` / `.quick-card`，例如“东莞非遗体验闯关应用”“今天吃什么外卖推荐应用”等胶囊按钮。
3. 点击一个真实提示词气泡按钮；不要点击应用卡片、banner、发送按钮或手动向输入框填值。
4. 读取上方需求输入框、textarea、contenteditable、uni-textarea 的 value/textContent/innerText 或相关 Vue/uni-app 绑定值。
5. 验证点击气泡后，上方输入框从空变为非空，并展示该气泡对应的完整提示词/需求文案。注意：气泡按钮可能只是短标题，输入框里可能展开为更长的完整需求，不要求逐字等于按钮短标题。
6. 记录页面状态、URL、被点击气泡 DOM/文案、输入框前后值和截图。

## 预期结果

1. 点击提示词气泡后，上方需求输入框成功显示对应提示词/完整需求文案。
2. 页面无白屏、无未处理报错，相关功能可继续操作。
3. 不要求点击提交，不要求等待 AI 回复或应用生成完成。

## 通过标准

- 必须点击真实提示词气泡按钮，并能在上方输入框中读取到非空的对应提示词/完整需求文案，才可 PASS。
- 气泡按钮短标题与输入框完整文案不完全一致时，只要输入框明确因本次点击从空变为非空，并包含相关主题词或完整需求，即可 PASS。
- 如果点击后只在页面其他区域看到文案，但输入框 value/textContent 为空，不可 PASS。
- 不允许用手动填充输入框替代气泡点击；气泡不存在或无法稳定定位时，应判 `FAIL`/`BLOCKED` 并记录原因。

## 失败条件

- 已进入需求澄清页面，但找不到任何可输入需求的控件。
- 点击提示词气泡后，无法在上方输入框或绑定值中读取到任何对应文案。
- 点击到了错误组件，例如应用卡片、banner、发送按钮、广告入口，导致输入框无变化。
- 页面出现错误状态或不可继续操作。

## 阻塞条件

- CF-P0-H5-039 无法进入需求澄清/创建应用页面，且本用例单独执行也无法进入。
- 登录态失效、H5 入口不可用、测试环境或必要数据不可用。

## 证据要求

- 点击前后截图。
- 页面 URL、气泡按钮选择器/DOM class、气泡文案。
- 输入框选择器、输入前后 value/textContent。

## 备注

- 本用例只验证“点击提示词气泡后，文案进入上方文本输入框”，不要提交生成，不要等待应用生成完成；生成链路属于其它用例。
