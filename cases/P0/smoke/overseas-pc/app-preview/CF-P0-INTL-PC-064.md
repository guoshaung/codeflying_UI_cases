# CF-P0-INTL-PC-064 进入应用管理后台后首次登录引导视频不应自动播放

- 优先级：P0
- 模块：海外主站 / 应用管理后台 / 首次登录引导
- 平台：海外PC
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：加载对应端的 Playwright session；选择稳定、已完成且非转圈的测试应用。
- Agent 分组：app_lifecycle_agent
- 账号类型：default-playwright-session
- 是否修改数据：no
- 数据锁：`none`
- 清理动作：无；仅使用已有稳定应用，不创建或修改数据
- 人工测试原因：无

## 测试步骤

1. 创建独立的海外 PC Browser Context，并加载总控传入的主站 Playwright session。
2. 导航到“我的应用”（`/my-apps`），选择稳定、已完成且非 `Developing...` 的应用，点击进入应用预览页。
3. 在预览页顶部菜单栏点击“后台”按钮，等待管理后台页面加载完成。
4. 后台页面加载后，定位首页引导视频；视频可能位于页面本体或同源 iframe 中。
5. 在视频首次出现时记录 `paused`、`currentTime`、`autoplay`、`readyState` 和当前 URL。
6. 等待 3 秒后再次记录；再等待 3 秒后记录第三次。采样期间不点击播放控件。
7. 记录操作前后截图，并将三次视频状态写入结果 JSON。

## 预期结果

1. 管理后台首页正常加载，无白屏、无未处理报错。
2. 首次登录引导视频不自动播放：首次状态 `paused === true`，且 3 秒、6 秒采样期间 `currentTime` 不持续增长。
3. 视频不带 `autoplay` 属性；`readyState` 仅作为加载状态记录，不能单独作为播放断言。

## 通过标准

- 点击“后台”后页面正常加载，无白屏、无未处理报错。
- 三次采样均满足 `paused === true`，且 `currentTime` 没有持续增长。
- `autoplay` 属性不存在或值为假，且页面证据完整。
- 自动化证据完整；若有重试，记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 管理后台在未点击播放的情况下自动播放视频，或 `currentTime` 持续增长。
- 页面白屏、报错或无法继续操作。

## 阻塞条件

- 测试环境、主站 session 或稳定应用不可用。

## 证据要求

- 进入管理后台前和首页加载完成后的截图。
- 管理后台 URL、登录状态和视频元素定位信息。
- 三次采样的 `paused`、`currentTime`、`autoplay`、`readyState` 和时间戳。

## 备注

- 本用例验证首次进入管理后台时的默认播放策略，不验证用户主动点击播放后的行为。
