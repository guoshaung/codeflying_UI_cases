# CF-P0-PC-051 进入对话页面

- 优先级：P0
- 模块：国内主站 / 应用创建 / 点击对话按钮
- 平台：国内PC
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：CF-P0-PC-050 已进入需求澄清/创建应用页面；或本用例自行进入 `https://www.codeflying.net/develop`。
- Agent 分组：pc_app_runner
- 账号类型：default-playwright-session
- 是否修改数据：yes
- 数据锁：`app:{app_id}`
- 清理动作：本用例只验证进入对话/收到反馈，不等待完整应用生成；通常无新应用需要清理。
- 人工测试原因：无
- XMind 原始标记：`priority-1`

## 测试步骤

1. 优先复用 CF-P0-PC-050 成功后的当前页面；若单独执行，则加载 `default-playwright-session` 并进入 `https://www.codeflying.net/develop`。
2. 定位需求输入框，输入稳定需求：`创建一个简单的待办事项应用`。
3. 点击“发送/提交/立即开发/开始生成/对话”等按钮。
4. 如果出现“选择生成类型/你想生成什么类型/网站/小程序/H5/应用”等请求确认卡片，选择默认推荐项或第一个可用项，并点击“确认/继续/开始生成/生成应用”。
5. 等待页面进入对话状态，或出现非空助手回复/生成进度/需求已接收提示。
6. 记录页面状态、URL、关键 DOM、接口结果和截图。

## 预期结果

1. 成功进入对话页面，或当前创建页出现对话消息、非空助手回复、生成进度、需求已接收提示之一。
2. 页面无白屏、无未处理报错，相关功能可继续操作。
3. 不要求等待完整应用生成或自动跳转预览页。

## 通过标准

- 出现“收到”“我先想想”“正在为你生成”“需求已接收”或与输入相关的非空助手回复即可 PASS。
- 如果请求确认卡片出现并成功确认，随后出现对话/进度/非空反馈，判 PASS；如果卡片确认通过 fallback 完成，标记 `RETRY_PASS`。
- 自动化证据完整；若有重试，必须记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 提交需求后没有任何响应、请求确认卡片无法确认、回复为空、接口报错或页面不可继续操作。

## 阻塞条件

- CF-P0-PC-050 无法进入创建/澄清页面，且本用例单独执行也无法进入。
- 登录态失效、官网/创建入口不可用、测试环境或必要数据不可用。

## 证据要求

- 操作前后截图。
- 页面 URL 与关键 DOM 状态。
- 请求确认卡片处理过程、助手首条反馈或生成进度证据。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。

## 备注

- 本用例坚持“收到回复即可”，不把后续应用未生成完成作为失败条件。
