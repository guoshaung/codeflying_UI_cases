# CF-P0-PC-044 点击立即开发按钮进入需求澄清页面

- 优先级：P0
- 模块：国内主站 / 应用创建 / 文本框内输入需求文案
- 平台：国内PC
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：加载对应端的 Playwright session；默认使用 `default-playwright-session`。
- Agent 分组：app_lifecycle_agent
- 账号类型：default-playwright-session
- 是否修改数据：yes
- 数据锁：`app:{app_id}`
- 清理动作：本用例只验证进入需求澄清页，不提交生成；通常无新应用需要清理。
- 人工测试原因：无

## 测试步骤

1. 创建独立的 国内PC Browser Context，并加载 `default-playwright-session`。
2. 打开 `https://www.codeflying.net/develop` 或从官网首页点击“立即开发/创建应用”进入创建入口。
3. 如果页面已有输入框，输入一段稳定需求，例如：`创建一个简单的待办事项应用`。
4. 点击“立即开发/开始创建/提交/发送”等创建入口，进入需求澄清或对话页面。
5. 如果出现“选择生成类型/你想生成什么类型/网站/小程序/H5/应用”等请求确认卡片，选择默认推荐项或第一个可用项，并点击“确认/继续/开始生成/生成应用”。
6. 记录页面状态、URL、关键 DOM、接口结果和截图。

## 预期结果

1. 点击立即开发/创建入口后进入需求澄清、创建应用或对话页面。
2. 页面无白屏、无未处理报错，相关功能可继续操作。

## 通过标准

- URL 进入创建/需求澄清/对话相关路由，或页面出现需求输入框、提示词气泡、创建应用按钮、需求澄清相关文案之一即可 PASS。
- 如果出现请求确认卡片，处理卡片后仍留在可继续输入/确认/生成的页面，也可判 PASS 或 `RETRY_PASS`。
- 自动化证据完整；若有重试，必须记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 创建入口存在，但点击和 fallback 后都无法进入任何需求澄清/创建应用/对话页面。
- 页面白屏、报错或无可继续操作的 UI。

## 阻塞条件

- 登录态失效、官网/创建入口不可用、测试环境或必要数据不可用。

## 证据要求

- 操作前后截图。
- 页面 URL 与关键 DOM 状态。
- 如出现请求确认卡片，记录卡片文案、所选默认项和确认动作。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。

## 备注

- 本用例只验证“进入需求澄清/创建页面”，不要求提交生成，不等待应用生成完成。
