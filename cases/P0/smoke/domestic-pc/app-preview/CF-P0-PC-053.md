# CF-P0-PC-053 点击发布按钮展示发布应用弹窗并可进入 H5 发布

- 优先级：P0
- 模块：国内主站 / 应用预览页 / 顶部功能
- 平台：国内PC
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：加载对应端的 Playwright session；需要应用时使用稳定、非转圈的测试应用。
- Agent 分组：app_publish_test_agent
- 账号类型：default-playwright-session
- 是否修改数据：yes
- 数据锁：`app:{app_id}`
- 清理动作：清理本轮创建的应用或恢复名称、发布状态
- 人工测试原因：无

## 测试步骤

1. 创建独立的 国内PC Browser Context，并按前置条件加载或清除登录态。
2. 进入当前账号拥有、加载稳定的应用预览页。
3. 点击页面顶部“发布”按钮。
4. 验证发布应用弹窗出现，并在弹窗内识别到“微信小程序发布”、“发布为H5端”和“发布为其他渠道”。
5. 点击“发布为H5端/网页应用”，验证出现 H5 发布弹窗或 H5 发布配置面板；不要确认真实发布、不要生成或识别二维码。
6. 截图后关闭弹窗。

## 预期结果

1. 点击发布按钮后发布应用弹窗正常出现，弹窗展示“微信小程序发布”、“发布为H5端”和“发布为其他渠道”三个一级渠道。
2. 选择“发布为H5端/网页应用”后，H5 发布弹窗或配置面板正常展示。
2. 页面无白屏、无未处理报错，相关功能可继续操作。

## 通过标准

- 发布应用弹窗可见，且能从弹窗 DOM/可见文本识别“微信小程序发布”“发布为H5端”和“发布为其他渠道”。
- 选择 H5 渠道后，H5 发布弹窗或配置面板可见；不要求确认发布、生成二维码或消耗发布额度。
- 自动化证据完整；若有重试，必须记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 发布应用弹窗未出现、缺少任一一级渠道，或选择 H5 渠道后未出现 H5 发布弹窗/配置面板。

## 阻塞条件

- 测试环境、账号、第三方服务或必要测试数据不可用。

## 证据要求

- 操作前后截图。
- 页面 URL 与关键 DOM 状态。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。
- 涉及数据变化时，保存变化前后数据及清理结果。

## 备注

- 发布验证只验证发布类型弹窗，不执行真实发布，不消耗发布额度。
