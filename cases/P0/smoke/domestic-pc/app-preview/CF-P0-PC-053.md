# CF-P0-PC-053 点击发布按钮 弹窗展示发布类型

- 优先级：P0
- 模块：国内主站 / 应用预览页 / 顶部功能
- 平台：国内PC
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：加载对应端的 Playwright session；需要应用时使用稳定、非转圈的测试应用。
- Agent 分组：app_publish_test_agent
- 账号类型：default-playwright-session
- 是否修改数据：yes
- 数据锁：`app:{app_id}`
- 清理动作：清理本轮创建的应用或恢复名称、发布状态
- 人工测试原因：无

## 测试步骤

1. 创建独立的 国内PC Browser Context，并按前置条件加载或清除登录态。
2. 进入当前账号拥有、加载稳定的应用预览页。
3. 点击页面顶部“发布”按钮。
4. 验证发布类型弹窗出现，并在弹窗内识别到“微信小程序发布”、“发布为H5端”和“发布为其他渠道”。
5. 截图后关闭弹窗；不要点击具体发布类型，不要生成/识别二维码，也不要真实发布。

## 预期结果

1. 点击发布按钮后发布类型弹窗正常出现，弹窗展示“微信小程序发布”、“发布为H5端”和“发布为其他渠道”三个一级渠道。
2. 页面无白屏、无未处理报错，相关功能可继续操作。

## 通过标准

- 发布类型弹窗可见，且能从弹窗 DOM/可见文本识别“微信小程序发布”“发布为H5端”和“发布为其他渠道”即 PASS；不要求展开其他渠道的细分选项，也不要求二维码出现或可识别。
- 自动化证据完整；若有重试，必须记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 发布类型弹窗未出现，或弹窗缺少“微信小程序发布”“发布为H5端”和“发布为其他渠道”任一类型。

## 阻塞条件

- 测试环境、账号、第三方服务或必要测试数据不可用。

## 证据要求

- 操作前后截图。
- 页面 URL 与关键 DOM 状态。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。
- 涉及数据变化时，保存变化前后数据及清理结果。

## 备注

- 发布验证只验证发布类型弹窗，不执行真实发布，不消耗发布额度。
