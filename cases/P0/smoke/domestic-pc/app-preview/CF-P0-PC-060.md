# CF-P0-PC-060 发布为其他渠道打开其他渠道弹窗

- 优先级：P0
- 模块：国内主站 / 应用预览页 / 预览和分享 / 发布状态
- 平台：国内PC
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：加载对应端的 Playwright session；需要应用时使用稳定、非转圈的测试应用。
- Agent 分组：app_publish_test_agent
- 账号类型：default-playwright-session
- 是否修改数据：yes
- 数据锁：`app:{app_id}`
- 清理动作：清理本轮创建的应用或恢复名称、发布状态
- 人工测试原因：无

## 测试步骤

1. 创建独立的 国内PC Browser Context，并按前置条件加载或清除登录态。
2. 进入当前账号拥有且已加载完成的应用预览页，点击顶部“发布”打开发布应用弹窗。
3. 点击“发布为其他渠道/其他渠道”入口。
4. 验证其他渠道弹窗或其他渠道配置面板出现。
5. 截图后关闭弹窗；不要确认真实发布，不要修改任何渠道配置。

## 预期结果

1. 发布为其他渠道入口可用，点击后正常展示其他渠道弹窗或配置面板。
2. 页面无白屏、无未处理报错，相关功能可继续操作。

## 通过标准

- 其他渠道弹窗或配置面板可见，且不需要确认发布、生成二维码或消耗发布额度。
- 自动化证据完整；若有重试，必须记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 其他渠道入口不存在、点击无响应，或其他渠道弹窗/配置面板未出现。

## 阻塞条件

- 测试环境、账号、第三方服务或必要测试数据不可用。

## 证据要求

- 操作前后截图。
- 页面 URL 与关键 DOM 状态。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。
- 涉及数据变化时，保存变化前后数据及清理结果。

## 备注

- 发布验证只验证发布类型弹窗，不执行真实发布，不消耗发布额度。
