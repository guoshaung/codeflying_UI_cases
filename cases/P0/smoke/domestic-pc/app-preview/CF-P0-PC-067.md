# CF-P0-PC-067 会员用户可关闭应用水印

- 优先级：P0
- 模块：国内主站 / 应用预览页 / 顶部功能 / 水印管理
- 平台：国内PC
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：付费用户
- 前置条件：加载固定会员测试账号 Playwright session；选择会员账号拥有、稳定且非 `Developing...` 的应用。
- Agent 分组：app_publish_test_agent
- 账号类型：member_account
- 是否修改数据：yes
- 数据锁：`app:{app_id}`
- 清理动作：记录并恢复本 case 操作前的水印开关状态
- 人工测试原因：无

## 测试步骤

1. 创建独立的国内PC Browser Context，加载 member session，进入会员账号自己的稳定应用预览页。
2. 通过顶部“更多/More”进入“水印管理/Watermark”，记录水印开关的原始状态并截图。
3. 当水印处于开启状态时，点击关闭水印开关；当原始状态已关闭时，先开启后再关闭，以验证关闭操作。
4. 等待水印状态更新接口业务成功，并断言水印开关呈关闭状态，页面未出现付费弹窗。
5. 截图并将水印开关恢复为步骤 2 记录的原始状态；记录恢复结果。

## 预期结果

1. 会员可正常关闭水印，不出现付费拦截。
2. 水印关闭状态在页面和业务接口中一致，恢复后与操作前一致。

## 通过标准

- 关闭操作后水印开关为关闭状态，且没有付费/升级/购买弹窗。
- 关闭接口业务成功；若界面没有可观测接口，则开关状态变化与再次进入页面后的状态一致。
- 原始状态已恢复，自动化证据完整；若有重试，必须记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 会员无法操作水印开关、关闭后仍为开启状态、出现付费拦截、接口业务失败，或原始状态无法恢复。

## 阻塞条件

- 会员 session、测试应用、水印管理入口或必要服务不可用。

## 证据要求

- 操作前、关闭后、恢复后的截图。
- 应用 ID、开关前后状态、接口结果和恢复结果。

## 备注

- 只允许操作本 case 选定的会员测试应用；结束前必须恢复原始水印状态。
