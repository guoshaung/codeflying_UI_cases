# CF-P0-PC-068 非会员用户关闭应用水印时展示付费弹窗

- 优先级：P0
- 模块：国内主站 / 应用预览页 / 顶部功能 / 水印管理
- 平台：国内PC
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户
- 前置条件：加载固定非会员测试账号 Playwright session；选择免费账号拥有、稳定且非 `Developing...` 的应用。
- Agent 分组：app_publish_test_agent
- 账号类型：free_account
- 是否修改数据：no
- 数据锁：`none`
- 清理动作：无；不得成功变更水印开关
- 人工测试原因：无

## 测试步骤

1. 创建独立的国内PC Browser Context，加载 free session，进入免费账号自己的稳定应用预览页。
2. 通过顶部“更多/More”进入“水印管理/Watermark”，记录水印开关初始状态并截图。
3. 点击关闭水印的开关或对应操作入口。
4. 断言展示付费/升级/购买弹窗，或业务接口明确返回需要会员权益；同时断言水印开关未被成功关闭。
5. 记录页面状态、URL、关键 DOM、接口结果和截图。

## 预期结果

1. 非会员尝试关闭水印时展示付费提示。
2. 未购买前，水印开关状态不发生成功变更。

## 通过标准

- 付费/升级/购买弹窗真实可见，或接口业务码明确表示无会员权益。
- 水印开关仍保持初始状态，未被置为关闭。
- 自动化证据完整；若有重试，必须记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 非会员可直接关闭水印、未出现付费提示、接口未体现权益限制，或页面不可继续操作。

## 阻塞条件

- 免费 session、测试应用、水印管理入口或必要服务不可用。

## 证据要求

- 操作前后截图。
- 应用 ID、开关初始和最终状态、付费弹窗或接口结果。

## 备注

- 本用例不执行购买，也不得通过改库或切换会员状态绕过权益校验。
