# CF-P0-PC-066 点击水印管理进入水印管理页面

- 优先级：P0
- 模块：国内主站 / 应用预览页 / 顶部功能 / 水印管理
- 平台：国内PC
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：加载对应端的 Playwright session；选择当前账号拥有、稳定且非 `Developing...` 的应用。
- Agent 分组：app_publish_test_agent
- 账号类型：default-playwright-session
- 是否修改数据：no
- 数据锁：`none`
- 清理动作：无；不修改水印开关
- 人工测试原因：无

## 测试步骤

1. 创建独立的国内PC Browser Context，并按前置条件加载登录态。
2. 进入当前账号拥有、加载稳定的应用预览页，点击顶部菜单栏的“更多/More”。
3. 点击“水印管理/Watermark”，断言进入水印管理页面或水印管理面板。
4. 记录页面状态、URL、关键 DOM、接口结果和截图；本 case 不点击水印开关。

## 预期结果

1. 点击水印管理后正常展示水印管理页面或面板。
2. 页面无白屏、无未处理报错，相关功能可继续操作。

## 通过标准

- 顶部更多入口和水印管理入口均可用，水印管理标题、开关或配置区域至少一项真实可见。
- 自动化证据完整；若有重试，必须记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 更多入口或水印管理入口不存在、点击无响应、水印管理页面或面板未出现，或页面不可继续操作。

## 阻塞条件

- 测试环境、账号、第三方服务或必要测试数据不可用。

## 证据要求

- 操作前后截图。
- 页面 URL 与关键 DOM 状态。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。

## 备注

- 本用例只验证进入水印管理页面，不验证或修改水印开关。
