# CF-P0-PC-013 切换页面语言并在验证后恢复中文

- 优先级：P0
- 模块：国内主站 / 顶部导航 / 语言选择
- 平台：国内PC
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：免费用户 / 付费用户
- 前置条件：加载对应端的 Playwright session；需要应用时使用稳定、非转圈的测试应用。
- Agent 分组：shell_navigation_agent
- 账号类型：default-playwright-session
- 是否修改数据：yes
- 数据锁：`none`
- 清理动作：主断言通过后必须切回中文，并确认页面已经恢复中文界面
- 人工测试原因：无

## 测试步骤

1. 创建独立的 国内PC Browser Context，并按前置条件加载或清除登录态。
2. 进入 FM 路径：`国内主站 / 顶部导航 / 语言选择`。
3. 打开语言选择器，选择任意一种非中文语言，确认页面主要文案切换为对应语言。
4. 完成语言切换断言后，再次打开语言选择器，选择“中文”或“简体中文”。
5. 确认页面主要文案已经恢复为中文；保存恢复中文后的截图和当前 URL。

## 预期结果

1. 选择非中文语言后，页面主要文案正确切换为对应语言。
2. 主断言完成后成功切回中文，页面主要文案恢复为中文。
3. 页面无白屏、无未处理报错，相关功能可继续操作。

## 通过标准

- 非中文语言切换断言通过，并且结束前已经恢复中文界面；缺少恢复中文的验证不得写 PASS。
- 自动化证据完整；若有重试，必须记录首次错误并标记 `RETRY_PASS`。

## 失败条件

- 语言未正确切换、切换后页面异常，或测试结束前无法恢复中文界面。

## 阻塞条件

- 测试环境、账号、第三方服务或必要测试数据不可用。

## 证据要求

- 切换前、切换到非中文语言后、恢复中文后的截图。
- 页面 URL 与关键 DOM 状态。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。
- 涉及数据变化时，保存变化前后数据及清理结果。

## 备注

- 恢复中文属于本用例的必做收尾步骤，不能留到后续用例处理。
