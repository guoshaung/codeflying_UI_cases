# CF-P0-INTL-H5-037 点击进入购买会员页面

- 优先级：P0
- 模块：海外H5 / 个人中心 / 会员类型 / 充值会员
- 平台：海外H5
- 执行方式：可自动化
- 问题类型：产品体验
- 用户类型：付费用户
- 前置条件：加载对应端的 Playwright session；需要应用时使用稳定、非转圈的测试应用。
- Agent 分组：`profile_support_agent`
- 账号类型：default-playwright-session
- 是否修改数据：yes
- 数据锁：`payment:{account_id}`
- 清理动作：使用 mock/沙箱；不得产生真实扣款
- 人工测试原因：真实支付完成需人工/沙箱专项；本用例只验证购买会员页面/弹窗入口。
- XMind 原始标记：`priority-1`

## 测试步骤

1. 创建独立的 海外H5 Browser Context，使用移动端 viewport，并加载 `default-playwright-session`。
2. 打开海外 H5 入口：`https://www.codeflying.app/`。
3. 必须先点击底部导航“个人中心”，进入真实个人中心页面；不能停留在首页/发现页直接查找“充值会员”。
4. 确认用户信息和会员卡片区域已渲染，页面应出现“尊享版/免费版/会员类型/在线客服/退出登录”等个人中心特征之一。
5. 点击“充值会员 / 立即购买 / 购买会员”等会员购买入口。
   - H5 个人中心按钮常绑定 Vue Router JS 事件（`javascript:void(0)` 或 `@click`），普通 Playwright `.click()` 可能不触发。
   - 点击优先级：`page.evaluate(() => targetElement.click())` → `locator.dispatchEvent('click')` → `click({ force: true })`。
   - 禁止只执行普通 `.click()` 后无跳转就直接判定 FAIL。
6. 等待购买会员页面、会员套餐弹窗、支付/积分包入口或等价购买 UI 出现。
7. 记录页面状态、URL、关键 DOM、接口结果和截图。

## 预期结果

1. 点击购买入口后，进入购买会员页面或展示会员套餐/支付相关弹窗。
2. 页面无白屏、无未处理报错，相关功能可继续操作。
3. 不要求真实付款成功。

## 通过标准

- 购买会员页面、会员套餐弹窗、支付二维码/金额区域、积分包/会员套餐入口之一正常出现即可 PASS。
- 如果因支付需要真人操作，只要购买入口和支付前置 UI 正常展示，可判自动化 PASS 或记录后续 `MANUAL_REQUIRED`。

## 失败条件

- 购买入口存在但按上述 JS 触发策略后仍无响应。
- 跳转/弹窗后页面白屏、报错或无法继续操作。

## 阻塞条件

- 登录态失效、H5 入口不可用、会员/支付服务不可用、测试环境或必要数据不可用。

## 证据要求

- 操作前后截图。
- 页面 URL 与关键 DOM 状态。
- 支付/会员套餐弹窗截图（如出现）。
- 相关业务接口结果；HTTP 200 仍需检查业务码与返回数据。

## 备注

- 本用例自动化边界是“进入购买会员页面/展示购买 UI”，不是完成真实支付。
