# 用例标签规则

每条用例至少需要包含以下标签：

- 优先级：P0 / P1 / P2
- 模块
- 平台
- 执行方式
- 问题类型
- 用户类型

## 优先级

- P0：核心流程走不下去，或影响商业化、数据安全、支付计费。
- P1：流程可以绕过，但明显影响体验、效率或转化。
- P2：轻微体验问题、低频边界问题。

拿不准时，先往高一级放，后续 review 再调整。

## 执行方式

- 可自动化：Playwright / Agent 可以独立验证。
- 真人依赖：需要人工扫码、真实支付、手机设备或人工判断。
- agent 行为评测：重点评估 Agent 回复质量、需求理解、改写能力。

## 问题类型

- 产品体验：页面、按钮、流程、接口、支付、发布、下载等产品功能。
- Agent体验：AI 理解、澄清、生成、修改、连续对话质量。
